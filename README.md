A small Python entry for the "The 3 AM Excuse" bounty. `main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`, and an AI judge compares entries pairwise on being on subject, originality, the wallet's voice, use of the 3 AM hour, and economy of wording. The line: "Denied: at 3 AM the scammers clock in, your brain clocks out, and I'm the only one on shift still reading the whole destination address."

## Run it
```sh
python3 main.py
```
